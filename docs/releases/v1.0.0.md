# Team Rental Desk v1.0.0 — First Public Release

简体中文见下方。

This is the first public release of Team Rental Desk, a local-first Windows desktop app for managing shared ChatGPT and Codex spaces, seats, payments, renewals, currencies, backups, shortcuts, and reminders.

## Download

- `Team-Rental-Desk-1.0.0-Setup.exe` — Windows 10/11 x64 installer
- `SHA256SUMS.txt` — installer integrity value

The installer is not code-signed. Windows SmartScreen may warn about an unrecognized publisher. Verify the SHA-256 value before selecting **More info → Run anyway**.

## Highlights

- Automatically detects standard Chrome profiles and creates a Windows shortcut pinned to the selected profile, target page, and optional space.
- Optional startup checks, bottom-right Windows notifications, and SMTP email reminders.
- Operations overview, spaces, and two child seats per space.
- Partial payments, 0% / 0.6% / 1.6% fees, renewals, and frozen historical exchange rates.
- History-preserving archive, restore, delete, and reversal behavior.
- Payment methods plus add/edit/enable/disable/delete currency management.
- Verified local backups with integrity and foreign-key checks.
- Optional local UI-lock password with no default password; it does not encrypt the database.
- No telemetry, advertising, crash reporting, automatic updater, or paid feature gate.

Official support is currently limited to Windows 10/11 x64. macOS and Linux are community-porting targets only.

# Team Rental Desk v1.0.0 — 首次公开发布

这是 Team Rental Desk 的第一次公开发布。它是一款本地优先的 Windows 桌面工具，用于管理共享 ChatGPT / Codex 空间、子位置、收款、续费、币种、备份、快捷方式和提醒。

## 下载文件

- `Team-Rental-Desk-1.0.0-Setup.exe` — Windows 10/11 x64 安装包
- `SHA256SUMS.txt` — 安装包完整性校验值

安装包暂未数字签名，Windows SmartScreen 可能提示未知发布者。请先核对 SHA-256，一致后再选择“更多信息 → 仍要运行”。

## 重点功能

- 自动识别标准 Chrome 独立用户，并创建固定使用所选用户、目标页面和可选关联空间的 Windows 快捷方式。
- 可选开机检查、右下角 Windows 系统通知和 SMTP 邮件提醒。
- 运营概览、空间管理以及每个空间最多 2 个子位置。
- 部分收款、0% / 0.6% / 1.6% 手续费、续费和冻结历史汇率。
- 保留流水的归档、恢复、运营删除和撤销逻辑。
- 支付渠道以及币种的新增、编辑、启停和安全删除。
- 经过完整性和外键检查的本地备份。
- 可选本机界面锁密码，没有内置默认密码；它不会加密数据库。
- 不含遥测、广告、崩溃上报、自动更新或付费功能墙。

目前只正式支持 Windows 10/11 x64；macOS 和 Linux 仅作为社区移植方向。
